# 캘린더 탭 검토 — 작업 묶음 (2026-11-27)

코드 읽기로 찾은 것. 각 묶음은 끝나면 커밋 허락 → 다음 묶음.
상태: ☐ 안 함 · ☑ 끝남

## 묶음 1 — 잘못 동작하는 것
- ☑ **C1** 디데이 일정을 수정하면 디데이가 풀림(수정 모달에 값이 안 넘어감)
- ☑ **C2** 시작일을 뒤로 바꾸면 저장 버튼이 이유 없이 꺼짐 → 종료일이 같은 기간만큼 따라감
- ☑ **C3** 일정의 첫 수정이 수정기록에 안 남음(undefined), 문서에 `id`·`isPersonal`이 같이 저장됨
- ☑ **C4** 필터(개인·커플)를 걸어도 날짜 창에는 전체 일정이 나옴
- ☑ **C5** 날짜 창의 "오늘은 …"이 오늘이 아닌 날에도 나옴 → "이 날은"
- ☑ **C6** '나만 보기' 일정이 달력에서 데이트 색으로 보임(색을 바꾼 적 없을 때)

## 묶음 2 — 수정기록 창
- ☐ 자세히 보기에 항목 이름 표시, 날짜 변경도 표시
- ☐ 종류 영문(`boyfriend`)·빈 값(디데이 끔) 표시 정리
- ☐ 누가 바꿨는지 표시
- ☐ 문구 '~어요'체
- ☐ 삭제된 일정·반복 묶음에 대한 불필요한 서버 조회 제거

## 묶음 3 — 다듬기
- ☐ 대체공휴일 표시
- ☐ 삭제 확인 창 진행 표시 + 오프라인에서 삭제가 멈추는 것(저장처럼 시간 제한)
- ☐ 날짜 창 목록에 기간·반복·디데이 표시, 빈 화면 문구
- ☐ 접근성: 이전·다음 달·닫기 버튼 이름, 삭제 확인·반복 범위 창 `useDialog`
- ☐ 색 직접 적은 곳 → 변수(Calendar.css 일정 색, DayModal·수정기록 아이콘 색)
- ☐ 삭제된 일정 주소로 들어오면 빈 "새 일정 추가" 창이 뜸
- ☐ 용어 통일: 개인 / 나만 보기

## 묶음 4 — 추가 후보 (추천: 2·3·4)
1. 시간 입력(알림·홈·요약까지 영향 — 따로 결정)
2. 연·월 바로 가기(제목 누르기)
3. 반복 일정 한 번만 날짜 옮기기
4. 일정별 수정기록(일정 모달에서)
5. 장소·링크 칸, 일정 검색
